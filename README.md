# SQL-анализ заказов, клиентов и продаж

## О проекте

Проект посвящён решению аналитических задач с помощью SQL на данных интернет-магазина.

В анализе используются данные о:

- заказах;
- товарах;
- клиентах;
- доставках;
- пользовательских сессиях.

Цель проекта — показать применение SQL для решения типовых задач продуктовой и коммерческой аналитики.

## Что было сделано

В проекте реализованы SQL-запросы для:

- поиска наиболее популярных товаров;
- анализа завершённых и незавершённых доставок;
- расчёта средней длительности пользовательских сессий;
- анализа состава заказов;
- анализа способов оплаты;
- поиска наиболее активных клиентов;
- сегментации клиентов по возрасту;
- определения популярных товарных категорий;
- анализа совместных покупок.

## Примеры аналитических задач

### Популярность товаров

Определяется товар с максимальным количеством уникальных заказов.

### Анализ доставок

Рассчитываются:

- даты с максимальным и минимальным количеством завершённых доставок;
- динамика незавершённых доставок по месяцам.

### Пользовательские сессии

Рассчитывается средняя продолжительность сессии по типам устройств.

### Клиентская аналитика

Определяются:

- Top-10 клиентов по количеству заказов;
- возрастные группы клиентов;
- наиболее популярная категория товаров внутри каждой возрастной группы.

Для ранжирования категорий используется CTE и оконная функция `ROW_NUMBER()`.

### Basket Analysis

С помощью self-join определяется товар, который чаще всего покупается вместе с заданным продуктом.
